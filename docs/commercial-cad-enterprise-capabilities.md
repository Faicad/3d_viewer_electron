# 商用 CAD 企业级能力介绍

## 1. PDM/PLM 对接

商用 CAD 的 PDM/PLM 集成不是"导入/导出"层面，而是**底层数据模型级联**：

- **SolidWorks + PDMWorks/3DExperience**：文件检入/检出时自动记录版本树、BOM 差异对比、审批工作流。模型内嵌的配置表（Configuration Publisher）可驱动 ERP 物料展开。
- **NX + Teamcenter**：Siemens 自家产品，集成最深。从需求→设计→工艺→制造→质检，所有变更在 Teamcenter 中形成**单向数据链**，NX 打开时自动加载最新批准版本，禁止编辑已冻结版本。
- **Catia + ENOVIA/3DEXPERIENCE**：同样达索生态。Catia 的 `Product Structure` 直接映射到 ENOVIA 的 PSN（Product Structure Node），工程变更单（ECO）触发模型自动升版，下游 CAM/NCC 程序被锁定需重新签发。

**本质差异**：FreeCAD 的版本管理在文件系统层（手动命名 `v1.fcstd`），商用 CAD 的版本管理在**元数据层**——谁、何时、为什么改了什么字段，都有落库审计日志。ISO 9001 / IATF 16949 审厂要求的就是这个日志，不是模型本身。

## 2. 原生 GD&T 语义

GD&T（Geometric Dimensioning & Tolerancing）是一种用符号语言定义零件几何允许偏差的工程标准体系，核心标准为 **ASME Y14.5**（北美）和 **ISO 1101**（国际）。

### 与"传统公差"的根本区别

| 传统 +/- 公差 | GD&T |
|---|---|
| 用文字/数字标注在尺寸旁 | 用符号框（Feature Control Frame）挂接在特征上 |
| 默认独立原则（每个尺寸各自为政） | 明确基准参考系（Datum Reference Frame），控制特征间关系 |
| 无法区分"形状误差"和"位置误差" | 细分 14 种几何公差，精确表达功能需求 |
| 合格判定往往更宽松或更严（模糊地带） | 有明确的公差带（Tolerance Zone）形状和补偿规则 |

### 14 种几何公差符号（分 5 类）

**1. 形状公差（Form）**
- **⏤ 直线度**：控制线要素的直度
- **⌓ 平面度**：控制面的平整程度
- **〇 圆度**：控制圆截面的真圆度
- **⌭ 圆柱度**：圆度 + 直线度的组合

**2. 轮廓公差（Profile）**
- **⌒ 线轮廓度**：控制任意曲线的形状
- **⌒ 面轮廓度**：控制任意曲面的形状——MBD 中最常用的符号，因为复杂曲面无法用 +/- 标注

**3. 定向公差（Orientation）**
- **// 平行度**：要素对基准的平行程度
- **⟂ 垂直度**：要素对基准的垂直程度
- **∠ 倾斜度**：要素对基准的指定角度偏差

**4. 定位公差（Location）**
- **⨁ 位置度**：最核心的 GD&T 符号——特征中心相对于理想位置的偏差（如文章案例中孔位偏移 0.12mm，就是位置度的概念）
- **◎ 同轴度**：两圆柱轴线的重合程度
- **⨂ 对称度**：特征对中心平面的对称程度

**5. 跳动公差（Runout）**
- **↗ 圆跳动**：绕基准旋转一圈，表面跳动的最大差值
- **↗↗ 全跳动**：绕基准旋转全程的表面跳动

### Feature Control Frame（特征控制框）

```
⨁   Ø0.1  |  A  |  B  |  C  |  M
 ↑     ↑      ↑     ↑     ↑     ↑
符号  公差值  基准A  基准B  基准C  最大实体条件
```

含义：该特征的轴心位置必须在 Ø0.1 的圆柱公差带内，参考基准 A、B、C 建立的坐标系，且可补偿最大实体条件（MMC）提供的额外公差。

### GD&T 在工厂的实际价值

1. **功能驱动**：设计者明确说出"这个孔可以在 ±0.2mm 范围内偏移，但必须垂直于底面 0.05mm 以内"——而不是笼统写 ±0.2mm
2. **合格判定可复现**：CMM 三坐标测量机读取 GD&T 标注自动生成检测程序，结果不受检测员主观判断影响
3. **公差补偿**：MMC/LMC（最大/最小实体条件）允许在特征偏离最大实体时获得额外公差——降低废品率但不牺牲装配功能
4. **MBD（Model-Based Definition）**：全部 GD&T 信息嵌入 3D 模型，取代 2D 图纸，是 STEP AP242 的核心语义

### 商用 CAD 中的实现

- **Catia 的 FTA (Functional Tolerancing & Annotation)**：GD&T 标注直接挂接在模型拓扑面上，面偏移、重生成后公差自动跟随。支持 ASME Y14.5 / ISO 1101 全标准，导出 STEP AP242 时语义不丢失。
- **NX 的 PMI (Product Manufacturing Information)**：3D 标注可直接驱动下游 CMM 检测程序（通过 DMIS 协议输出），修改设计后检测路径自动更新。
- **SolidWorks DimXpert + MBD**：同样支持 3D 标注，输出到 eDrawings / 3D PDF / STEP AP242，下游供应商打开即可读出公差要求。

### 为什么 FreeCAD 的 GD&T 不够用

FreeCAD 的 GD&T 依赖于 Drawing Workbench 的文字注释或社区插件（如 GD&T Workbench），本质上是在模型上贴文字：

- 标注不绑定模型拓扑——修改模型后标注可能悬空或丢失
- 无法导出语义化的 AP242——下游 CMM 读不到公差信息
- 不支持 MMC/LMC 等高级规则——对于量产装配场景不可用
- 没有基准参考系的一致性校验——设计者可能标了逻辑矛盾的公差

**本质差异**：FreeCAD 的 GD&T 是**图形附着的文本**——模型拓扑变了，标注可能脱离面或丢失语义。商用 CAD 的 GD&T 是**模型的一部分**——是 CMM 检测程序、MBD 交付物、审厂台账的直接数据来源。

## 3. 工业级 CAM 后置处理

商用 CAM 的"工业级"体现在三件事：**机床数据库 + 后处理定制 + 加工仿真验证**：

- **NX CAM**：内置数千种工业机床运动学模型（德玛吉、马扎克、牧野等），后置处理器可编译为 `.def`/`.tcl` 定制脚本，输出 G 代码适配具体机床系统（Fanuc、Siemens 840D、Heidenhain）。加工仿真支持全机床碰撞检测、主轴负载预测、刀具磨损补偿。
- **Catia + Delmia**：达索体系，CAM 路径参数可溯源到设计特征的 GD&T 公差——即 **公差驱动 CAM**。刀路根据公差等级自动调整步距/进给。
- **SolidWorks CAM (CAMWorks 内核)**：基于特征的自动刀路识别，支持"知识库"——同一类特征（如钻孔）的加工参数可标准化签出，确保不同工艺员输出一致。

**本质差异**：FreeCAD 的 Path Workbench 生成的 G 代码：①缺乏机床特定运动学模型（碰撞检测弱）；②后置处理器数量有限且社区维护；③**无法输出可审计的加工参数台账**（用了几号刀、转速多少、切削深度多少，没有结构化的工程记录）。在 ISO 9001 审厂中，"刀具台账必须有据可查"是硬要求，FreeCAD 的 G 代码无法满足这一点。

---

## 一句话总结

> 商用 CAD 卖的不是建模功能，而是**一整条从设计意图到车间执行的可追溯链**。这条链的每一个节点都有审计日志、有工程签名、有标准对照——这才是工厂愿意付年费的理由。
