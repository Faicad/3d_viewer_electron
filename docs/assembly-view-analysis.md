# vise.3mf 装配视图问题分析

## 根因：3MF 文件的装配变换(assemble transforms)数据本身将不同子装配体放置在完全不同的 XY 坐标上

## 详细分析

### 数据概览

| 视图 | 21 个零件中的位置分布 | 视觉表现 |
|------|----------------------|---------|
| **打印视图** (默认) | 零件在打印平台上排版，跨 Plate 1/2 | 分盘显示，每盘居中 |
| **导入视图** | 所有零件 XY 偏差 < 120mm，比较集中 | "基本正常" |
| **装配视图** | **13 个零件在原点附近** vs **8 个在 90~313mm 远处** | "部分装配成功，部分散落" |

### 装配视图中"散落的"零件

| 零件 | 装配坐标 (XY) | 距离主体 |
|------|-------------|---------|
| holder_1 / holder_2 | **(259.8, -153.7)** | ~300mm |
| screw1(1) ×3 (obj 25/26/27) | **(313.4, 33~73)** | ~310mm |
| rail left (obj 30) | (90.0, -117.0) | ~148mm |
| jaw_21(1) (obj 33) | (90.0, -98.0) | ~133mm |
| safty (obj 35) | (90.0, -126.0) | ~155mm |

这些零件的装配变换（来自 `<assemble>` 块）本身就把它们放在了离主体 (~300mm) 远的位置。

### 对比：导入视图为何"基本正常"

导入变换（来自 `<part>` 内的 `<metadata key="matrix">`）将零件放回原始 CAD 导入位置：

| 零件 | 导入坐标 (XY) | 
|------|--------------|
| screws obj 24-27 | (0.0, -96.2) — **4个完全重叠** |
| vise body | (0.0, 0.0) |
| holder_1 | (0.0, 0.0) — 与主体在一起 |
| jaws | (0.0, ~-1.5~-88.5) |
| safty | (0.0, -121.9) |

导入视图中，所有零件的 XY 偏差在 ~120mm 范围内，比装配视图的 ~310mm 集中得多。

### 数学验证

`computeViewDelta` 的公式正确：
```
delta = M_assemble × M_build⁻¹
final_baked = delta × (M_build × M_component) = M_assemble × M_component
```

多组件对象（obj 19 "vise body" 有 2 个 component, obj 22 "holder" 有 2 个 component）正确保留了组件级偏移。测试验证了所有 21 个零件都能得到非 null 的 delta。

### 结论

**这不是代码 bug，而是 vise.3mf 本身的 `<assemble>` 数据将不同子装配体（holder、screws、rails）放在了远离主体 (~300mm) 的位置。** 装配视图中"散落的"零件就是这些子装配体，它们在 3MF 的装配定义中本就不在主体附近。

如果希望装配视图显示紧凑的装配体，需要对装配变换做后处理（例如检测并合并聚类），或者修改 3MF 源文件中的 assemble transform 数据。
