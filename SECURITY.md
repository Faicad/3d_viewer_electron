# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities by creating a private advisory at:

https://github.com/Faicad/3d_viewer_electron/security/advisories/new

You should receive a response within 72 hours. If you don't, please follow up via the advisory.

Do **not** report security vulnerabilities via public GitHub issues, discussions, or pull requests.

## What to Include

- A clear description of the vulnerability
- Steps to reproduce it
- Affected versions
- Any potential impact

## Policy

We will acknowledge receipt within 3 business days, and aim to resolve critical issues within 14 days.
