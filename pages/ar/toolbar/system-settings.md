# إعدادات النظام

انقر على زر **إعدادات النظام** في شريط الأدوات لفتح لوحة إعدادات التطبيق وتكوين التفضيلات.

تشمل خيارات الإعدادات:

- **اللغة** — التبديل بين الواجهة الصينية والإنجليزية
- **المظهر** — الوضع الفاتح / الوضع الداكن / اتباع النظام
- **الدليل الافتراضي** — تعيين دليل الملفات الافتراضي عند بدء التشغيل

![](/screenshots/toolbar/en/system-settings-panel.png)

جميع الإعدادات تدخل حيز التنفيذ فورًا دون إعادة تشغيل التطبيق.
