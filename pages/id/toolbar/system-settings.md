# Pengaturan Sistem

Klik tombol **Pengaturan Sistem** di bilah alat untuk membuka panel pengaturan aplikasi dan mengonfigurasi preferensi.

Opsi pengaturan:

- **Bahasa** — Beralih antara antarmuka China dan Inggris
- **Tema** — Mode terang / Mode gelap / Ikuti sistem
- **Direktori Default** — Mengatur direktori file default saat startup

![](/screenshots/toolbar/en/system-settings-panel.png)

Semua pengaturan langsung berlaku tanpa perlu memulai ulang aplikasi.
