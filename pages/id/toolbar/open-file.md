# Buka File

Klik tombol **Buka File** di bilah alat untuk membuka dialog pemilihan file asli OS dan memuat file model 3D.

Anda juga dapat menyeret dan menjatuhkan file langsung ke jendela, atau menempel dari clipboard (salin file lalu tekan `Ctrl+V`).

![](/screenshots/toolbar/en/open-file-dialog.png)

Setelah dimuat, panel kanan secara otomatis mendaftar semua file 3D yang didukung di direktori yang sama untuk peralihan cepat.

![](/screenshots/toolbar/en/file-list-after-open.png)
