# Ganti Sumbu

Klik tombol **Y↑** / **Z↑** di bilah alat untuk mengalihkan orientasi sumbu naik global.

Aplikasi secara otomatis memilih orientasi default berdasarkan jenis model:

- **Model CAD** (STL / STEP / 3MF dll.): **Z-atas (Z↑)** secara default
- **Model GLB / glTF**: **Y-atas (Y↑)** secara default

`vise.3mf` yang saat ini dimuat adalah file 3MF, ditampilkan dengan Z↑ secara default.

## Mode Z↑

Menggunakan sumbu Z sebagai arah ke atas, cocok untuk model arsitektur, CAD, dan teknik.

![](/screenshots/toolbar/en/axis-z-up.png)

## Mode Y↑

Menggunakan sumbu Y sebagai arah ke atas, cocok untuk sebagian besar model 3D dan aset game.

![](/screenshots/toolbar/en/axis-y-up.png)

Indikator sumbu koordinat di pojok kanan bawah diperbarui secara sinkron setelah peralihan.
