# Manajemen Cache

Klik tombol **Manajemen Cache** di bilah alat untuk membuka panel pengaturan cache dan mengelola data cache aplikasi.

Fitur:

- **Lihat Penggunaan Cache** — Menampilkan ruang disk yang ditempati oleh data cache
- **Bersihkan Cache** — Menghapus semua data cache dengan satu klik
- **Rincian Cache** — Melihat penggunaan berdasarkan jenis cache (konversi model, thumbnail, dll.)

![](/screenshots/toolbar/en/cache-management-panel.png)

Pembersihan cache secara teratur membebaskan ruang disk. Disarankan sebelum memuat model besar.
