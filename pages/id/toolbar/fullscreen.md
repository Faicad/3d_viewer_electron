# Layar Penuh

Klik tombol **Layar Penuh** di bilah alat untuk mengalihkan viewport ke mode layar penuh, menyembunyikan semua panel dan bilah alat untuk memaksimalkan area tampilan 3D.

Tekan `Esc` atau klik tombol lagi untuk keluar dari mode layar penuh.

![](/screenshots/toolbar/en/fullscreen-viewport.png)

Ideal untuk fokus pada detail model atau melakukan presentasi.
