# Pengaturan Render

Klik tombol **Pengaturan Render** di bilah alat untuk membuka panel parameter render dan menyesuaikan efek tampilan adegan.

Parameter yang dapat disesuaikan:

- **Peta Lingkungan** — Beralih peta lingkungan HDR yang berbeda untuk variasi pencahayaan
- **Hamparan Wireframe** — Mengaktifkan/menonaktifkan tampilan wireframe
- **Warna Latar** — Mengubah warna latar belakang viewport
- **Bayangan** — Mengaktifkan atau menonaktifkan rendering bayangan

![](/screenshots/toolbar/en/render-settings-panel.png)

Perubahan tercermin di viewport secara real-time.
