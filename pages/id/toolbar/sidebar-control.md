# Kontrol Bilah Samping

Bilah alat menyediakan tombol **Panel Kiri** dan **Panel Kanan** untuk mengalihkan visibilitas bilah sisi kiri dan kanan secara independen.

## Panel Kiri

Menampilkan pohon adegan dengan struktur hierarkis model.

Klik untuk mengalihkan visibilitas:

![](/screenshots/toolbar/en/sidebar-left-visible.png)

Disembunyikan untuk memberikan lebih banyak ruang viewport:

![](/screenshots/toolbar/en/sidebar-left-hidden.png)

## Panel Kanan

Menampilkan daftar file dan informasi model.

Klik untuk mengalihkan visibilitas:

![](/screenshots/toolbar/en/sidebar-right-visible.png)

![](/screenshots/toolbar/en/sidebar-right-hidden.png)

Kedua panel dikontrol secara independen untuk tata letak ruang kerja yang fleksibel.
