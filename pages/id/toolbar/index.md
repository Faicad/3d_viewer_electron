# Bilah Alat

Bilah alat menyediakan tombol akses cepat untuk fitur-fitur yang sering digunakan. Bagian ini memperkenalkan fungsi dan efek setiap tombol.

::: tip
Model demo `vise.3mf` digunakan secara default untuk ilustrasi.
:::

## Daftar Fungsi

- [Buka File](/id/toolbar/open-file) — Memuat model 3D dari penyimpanan lokal
- [Ganti Sumbu](/id/toolbar/axis-switch) — Beralih antara orientasi Y↑ dan Z↑
- [Mode Perspektif](/id/toolbar/perspective-mode) — Beralih antara proyeksi perspektif dan ortografis
- [Manajer Material](/id/toolbar/material-manager) — Melihat dan mengedit properti material model
- [Pengaturan Render](/id/toolbar/render-settings) — Menyesuaikan parameter render dan efek visual
- [Pemutar Animasi](/id/toolbar/animation-player) — Memutar data animasi yang tertanam dalam model
- [Manajemen Alas](/id/toolbar/bed-management) — Visualisasi dan pengaturan alas cetak 3D
- [Riwayat](/id/toolbar/history) — Melihat model yang pernah dimuat sebelumnya
- [Info Model](/id/toolbar/model-info) — Melihat informasi detail tentang model saat ini
- [Layar Penuh](/id/toolbar/fullscreen) — Mengalihkan mode tampilan layar penuh
- [Kontrol Bilah Samping](/id/toolbar/sidebar-control) — Menampilkan/menyembunyikan panel kiri dan kanan
- [Manajemen Cache](/id/toolbar/cache-management) — Mengelola data cache aplikasi
- [Pengaturan Sistem](/id/toolbar/system-settings) — Mengonfigurasi preferensi aplikasi
