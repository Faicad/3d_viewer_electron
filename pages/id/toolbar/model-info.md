# Info Model

Klik tombol **Info Model** di bilah alat untuk membuka panel info model dan melihat data detail tentang model saat ini.

Informasi yang ditampilkan meliputi:

- **Jumlah Vertex** — Total jumlah vertex
- **Jumlah Wajah** — Total jumlah segitiga
- **Ukuran File** — Ruang file model pada disk
- **Bounding Box** — Dimensi model sepanjang sumbu X/Y/Z
- **Jumlah Material** — Jumlah material yang digunakan
- **Format File** — Jenis format file yang dimuat
