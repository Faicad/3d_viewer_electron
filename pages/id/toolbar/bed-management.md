# Manajemen Alas

Klik tombol **Manajemen Alas** di bilah alat untuk mengalihkan visibilitas alas cetak 3D.

Aplikasi secara otomatis menentukan status awal berdasarkan jenis model:

- **Model CAD** (STL / STEP / 3MF dll.): **alas ditampilkan** secara default
- **Model Lainnya** (GLB / OBJ / PLY dll.): **alas disembunyikan** secara default

`vise.3mf` yang saat ini dimuat adalah file 3MF, sehingga alas ditampilkan secara default.

![](/screenshots/toolbar/en/bed-management-panel.png)

Ideal untuk pengguna cetak 3D untuk melihat pratinjau penempatan model sebelum slicing.
