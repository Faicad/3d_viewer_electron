# Manajer Material

Klik tombol **Manajer Material** di bilah alat untuk membuka panel edit material dan melihat/mengedit properti material model saat ini.

Mendukung penyesuaian parameter berikut:

- **Warna** — Mengubah warna dasar material
- **Metalness** — Mengontrol tampilan logam dari material
- **Kekasaran** — Mengontrol kehalusan permukaan
- **Opacity** — Menyesuaikan transparansi material

![](/screenshots/toolbar/en/material-manager-panel.png)

Semua penyesuaian berlaku secara real-time untuk pratinjau material yang cepat.
