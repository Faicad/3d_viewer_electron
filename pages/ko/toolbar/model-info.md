# 모델 정보

도구 모음의 **모델 정보** 버튼을 클릭하여 모델 정보 패널을 열고 현재 모델의 상세 데이터를 확인합니다.

표시되는 정보:

- **정점 수** — 모델의 총 정점 수
- **면 수** — 모델의 총 삼각형 수
- **파일 크기** — 디스크 상의 모델 파일 크기
- **경계 상자** — X/Y/Z 축을 따른 모델 치수
- **재질 수** — 사용된 재질 수
- **파일 형식** — 불러온 파일 형식 유형

![](/screenshots/toolbar/en/model-info-panel.png)

모델의 기본 통계를 한눈에 빠르게 확인할 수 있습니다.
