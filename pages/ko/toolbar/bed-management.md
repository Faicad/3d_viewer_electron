# 베드 관리

도구 모음의 **베드 관리** 버튼을 클릭하여 3D 프린팅 베드 표시를 전환합니다.

앱이 모델 유형에 따라 초기 상태를 자동으로 결정합니다:

- **CAD 모델**(STL / STEP / 3MF 등): 기본적으로 **베드 표시**
- **기타 모델**(GLB / OBJ / PLY 등): 기본적으로 **베드 숨김**

현재 불러온 `vise.3mf`는 3MF 파일이므로 베드가 기본적으로 표시됩니다.

![](/screenshots/toolbar/en/bed-management-panel.png)

3D 프린팅 사용자가 슬라이싱 전에 모델 배치를 미리 보기에 적합합니다.
