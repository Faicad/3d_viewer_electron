# 원근 모드

도구 모음의 **원근/직교** 버튼을 클릭하여 원근 투영과 직교 투영 간을 전환합니다.

## 원근 모드

인간 눈의 원근감을 시뮬레이션 — 먼 물체일수록 작게 표시됩니다. 깊이와 공간 관계를 관찰하는 데 이상적입니다.

![](/screenshots/toolbar/en/perspective-mode.png)

## 직교 모드

원근 왜곡을 제거 — 거리에 관계없이 모든 물체가 동일한 크기로 표시됩니다. 치수와 정렬을 확인하는 데 적합합니다.

![](/screenshots/toolbar/en/orthographic-mode.png)
