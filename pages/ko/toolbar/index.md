# 도구 모음

도구 모음은 자주 사용하는 기능에 빠르게 접근할 수 있는 버튼을 제공합니다. 이 섹션에서는 각 버튼의 기능과 효과를 소개합니다.

::: tip
설명에는 기본적으로 데모 모델 `vise.3mf`를 사용합니다.
:::

## 기능 목록

- [파일 열기](/ko/toolbar/open-file) — 로컬 저장소에서 3D 모델 불러오기
- [축 전환](/ko/toolbar/axis-switch) — Y↑와 Z↑ 방향 전환
- [원근 모드](/ko/toolbar/perspective-mode) — 원근 투영과 직교 투영 전환
- [재질 관리](/ko/toolbar/material-manager) — 모델 재질 속성 보기 및 편집
- [렌더링 설정](/ko/toolbar/render-settings) — 렌더링 매개변수 및 시각 효과 조정
- [애니메이션 플레이어](/ko/toolbar/animation-player) — 모델에 포함된 애니메이션 데이터 재생
- [베드 관리](/ko/toolbar/bed-management) — 3D 프린팅 베드 시각화 및 설정
- [기록](/ko/toolbar/history) — 이전에 불러온 모델 보기
- [모델 정보](/ko/toolbar/model-info) — 현재 모델의 상세 정보 보기
- [전체 화면](/ko/toolbar/fullscreen) — 전체 화면 표시 모드 전환
- [사이드바 제어](/ko/toolbar/sidebar-control) — 왼쪽/오른쪽 패널 표시/숨기기
- [캐시 관리](/ko/toolbar/cache-management) — 애플리케이션 캐시 데이터 관리
- [시스템 설정](/ko/toolbar/system-settings) — 애플리케이션 환경 설정 구성
