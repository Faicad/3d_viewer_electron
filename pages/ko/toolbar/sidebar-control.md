# 사이드바 제어

도구 모음에는 **왼쪽 패널**과 **오른쪽 패널** 버튼이 있어 좌우 사이드바의 표시를 독립적으로 전환할 수 있습니다.

## 왼쪽 패널

모델의 계층 구조를 가진 씬 트리를 표시합니다.

클릭하여 표시/숨기기 전환:

![](/screenshots/toolbar/en/sidebar-left-visible.png)

숨겨서 더 많은 뷰포트 공간 확보:

![](/screenshots/toolbar/en/sidebar-left-hidden.png)

## 오른쪽 패널

파일 목록과 모델 정보를 표시합니다.

클릭하여 표시/숨기기 전환:

![](/screenshots/toolbar/en/sidebar-right-visible.png)

![](/screenshots/toolbar/en/sidebar-right-hidden.png)

두 패널은 독립적으로 제어되어 유연한 작업 공간 레이아웃이 가능합니다.
