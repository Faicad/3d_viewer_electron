# 파일 열기

도구 모음의 **파일 열기** 버튼을 클릭하여 OS 네이티브 파일 선택 대화상자를 열고 3D 모델 파일을 불러옵니다.

파일을 창에 직접 드래그 앤 드롭하거나 클립보드에서 붙여넣을 수도 있습니다(파일을 복사한 후 `Ctrl+V` 누르기).

![](/screenshots/toolbar/en/open-file-dialog.png)

불러온 후 오른쪽 패널에 같은 디렉토리의 지원되는 3D 파일이 자동으로 나열되어 빠르게 전환할 수 있습니다.

![](/screenshots/toolbar/en/file-list-after-open.png)
