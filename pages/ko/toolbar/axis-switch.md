# 축 전환

도구 모음의 **Y↑** / **Z↑** 버튼을 클릭하여 전역 상향 축 방향을 전환합니다.

앱이 모델 유형에 따라 기본 방향을 자동으로 선택합니다:

- **CAD 모델**(STL / STEP / 3MF 등): 기본적으로 **Z-up (Z↑)**
- **GLB / glTF 모델**: 기본적으로 **Y-up (Y↑)**

현재 불러온 `vise.3mf`는 3MF 파일이므로 기본적으로 Z↑로 표시됩니다.

## Z↑ 모드

Z축을 위쪽 방향으로 사용합니다. 건축, CAD 및 엔지니어링 모델에 적합합니다.

![](/screenshots/toolbar/en/axis-z-up.png)

## Y↑ 모드

Y축을 위쪽 방향으로 사용합니다. 대부분의 3D 모델링 및 게임 자산에 적합합니다.

![](/screenshots/toolbar/en/axis-y-up.png)

전환 후 오른쪽 아래의 좌표축 표시기가 동기화되어 업데이트됩니다.
