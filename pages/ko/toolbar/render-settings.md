# 렌더링 설정

도구 모음의 **렌더링 설정** 버튼을 클릭하여 렌더링 매개변수 패널을 열고 장면 표시 효과를 조정합니다.

조정 가능한 매개변수:

- **환경 맵** — 다양한 HDR 환경 맵으로 전환하여 조명 변경
- **와이어프레임 오버레이** — 와이어프레임 표시 오버레이 켜기/끄기
- **배경 색상** — 뷰포트 배경색 변경
- **그림자** — 그림자 렌더링 활성화/비활성화

![](/screenshots/toolbar/en/render-settings-panel.png)

변경 사항이 뷰포트에 실시간으로 반영됩니다.
