# ツールバー

ツールバーはよく使う機能へのクイックアクセスボタンを提供します。このセクションでは各ボタンの機能と効果を紹介します。

::: tip
説明にはデフォルトでデモモデル `vise.3mf` を使用しています。
:::

## 機能一覧

- [ファイルを開く](/ja/toolbar/open-file) — ローカルストレージから3Dモデルを読み込む
- [軸の切り替え](/ja/toolbar/axis-switch) — Y↑ と Z↑ の方向を切り替え
- [透視モード](/ja/toolbar/perspective-mode) — 透視投影と正射投影を切り替え
- [マテリアル管理](/ja/toolbar/material-manager) — モデルのマテリアルプロパティを表示・編集
- [レンダリング設定](/ja/toolbar/render-settings) — レンダリングパラメータと視覚効果を調整
- [アニメーションプレーヤー](/ja/toolbar/animation-player) — モデルに埋め込まれたアニメーションデータを再生
- [ベッド管理](/ja/toolbar/bed-management) — 3Dプリントベッドの表示と設定
- [履歴](/ja/toolbar/history) — 以前に読み込んだモデルを表示
- [モデル情報](/ja/toolbar/model-info) — 現在のモデルの詳細情報を表示
- [全画面表示](/ja/toolbar/fullscreen) — 全画面表示モードに切り替え
- [サイドバー制御](/ja/toolbar/sidebar-control) — 左右パネルの表示/非表示
- [キャッシュ管理](/ja/toolbar/cache-management) — アプリケーションキャッシュデータを管理
- [システム設定](/ja/toolbar/system-settings) — アプリケーションの設定を構成
