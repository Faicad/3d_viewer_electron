# モデル情報

ツールバーの **モデル情報** ボタンをクリックして、モデル情報パネルを開き、現在のモデルの詳細データを表示します。

表示される情報：

- **頂点数** — モデルの頂点の総数
- **面数** — モデルの三角形の総数
- **ファイルサイズ** — ディスク上のモデルファイルサイズ
- **バウンディングボックス** — X/Y/Z軸に沿ったモデルの寸法
- **マテリアル数** — 使用されているマテリアルの数
- **ファイル形式** — 読み込まれたファイル形式の種類

![](/screenshots/toolbar/en/model-info-panel.png)

モデルの基本統計情報をひと目で確認できます。
