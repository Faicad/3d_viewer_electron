# ファイルを開く

ツールバーの **ファイルを開く** ボタンをクリックして、OSネイティブのファイル選択ダイアログを開き、3Dモデルファイルを読み込みます。

ファイルをウィンドウに直接ドラッグ＆ドロップするか、クリップボードから貼り付ける（ファイルをコピーして `Ctrl+V` を押す）こともできます。

![](/screenshots/toolbar/en/open-file-dialog.png)

読み込み後、右パネルに同じディレクトリ内のサポートされている3Dファイルが自動的に一覧表示され、素早く切り替えられます。

![](/screenshots/toolbar/en/file-list-after-open.png)
