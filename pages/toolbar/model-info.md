# Model Info

Click the **Model Info** button in the toolbar to open the model info panel and view detailed data about the current model.

Displayed information includes:

- **Vertex Count** — Total number of vertices
- **Face Count** — Total number of triangles
- **File Size** — Model file size on disk
- **Bounding Box** — Model dimensions along X/Y/Z axes
- **Material Count** — Number of materials used
- **File Format** — Type of loaded file format
