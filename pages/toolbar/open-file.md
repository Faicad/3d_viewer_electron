# Open File

Click the **Open File** button in the toolbar to open the native OS file selection dialog and load a 3D model file.

You can also drag & drop files directly into the window, or paste from clipboard (copy a file then press `Ctrl+V`).

![](/screenshots/toolbar/en/open-file-dialog.png)

Once loaded, the right panel automatically lists all supported 3D files in the same directory for quick switching.

![](/screenshots/toolbar/en/file-list-after-open.png)
