# Control de barra lateral

La barra de herramientas proporciona botones de **Panel izquierdo** y **Panel derecho** para activar/desactivar de forma independiente la visibilidad de las barras laterales izquierda y derecha.

## Panel izquierdo

Muestra el árbol de la escena con la estructura jerárquica del modelo.

Haga clic para alternar la visibilidad:

![](/screenshots/toolbar/en/sidebar-left-visible.png)

Oculto para liberar más espacio en el visor:

![](/screenshots/toolbar/en/sidebar-left-hidden.png)

## Panel derecho

Muestra la lista de archivos y la información del modelo.

Haga clic para alternar la visibilidad:

![](/screenshots/toolbar/en/sidebar-right-visible.png)

![](/screenshots/toolbar/en/sidebar-right-hidden.png)

Ambos paneles se controlan de forma independiente para una disposición flexible del espacio de trabajo.
