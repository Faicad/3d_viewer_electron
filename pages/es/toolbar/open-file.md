# Abrir archivo

Haga clic en el botón **Abrir archivo** de la barra de herramientas para abrir el diálogo nativo de selección de archivos del sistema operativo y cargar un archivo de modelo 3D.

También puede arrastrar y soltar archivos directamente en la ventana, o pegar desde el portapapeles (copie un archivo y pulse `Ctrl+V`).

![](/screenshots/toolbar/en/open-file-dialog.png)

Una vez cargado, el panel derecho lista automáticamente todos los archivos 3D compatibles en el mismo directorio para cambiar rápidamente.

![](/screenshots/toolbar/en/file-list-after-open.png)
