# Barra de herramientas

La barra de herramientas proporciona botones de acceso rápido para las funciones más utilizadas. Esta sección presenta la función y el efecto de cada botón.

::: tip
El modelo de demostración `vise.3mf` se utiliza por defecto para las ilustraciones.
:::

## Lista de funciones

- [Abrir archivo](/es/toolbar/open-file) — Cargar modelos 3D desde el almacenamiento local
- [Cambio de eje](/es/toolbar/axis-switch) — Alternar entre orientación Y↑ y Z↑
- [Modo de perspectiva](/es/toolbar/perspective-mode) — Cambiar entre proyección perspectiva y ortográfica
- [Gestor de materiales](/es/toolbar/material-manager) — Ver y editar propiedades de materiales del modelo
- [Configuración de renderizado](/es/toolbar/render-settings) — Ajustar parámetros de renderizado y efectos visuales
- [Reproductor de animaciones](/es/toolbar/animation-player) — Reproducir datos de animación incrustados en modelos
- [Gestión de cama](/es/toolbar/bed-management) — Visualización y configuración de la cama de impresión 3D
- [Historial](/es/toolbar/history) — Ver modelos cargados anteriormente
- [Información del modelo](/es/toolbar/model-info) — Ver información detallada del modelo actual
- [Pantalla completa](/es/toolbar/fullscreen) — Alternar modo de pantalla completa
- [Control de barra lateral](/es/toolbar/sidebar-control) — Mostrar/ocultar paneles izquierdo y derecho
- [Gestión de caché](/es/toolbar/cache-management) — Gestionar datos de caché de la aplicación
- [Configuración del sistema](/es/toolbar/system-settings) — Configurar preferencias de la aplicación
