# แถบเครื่องมือ

แถบเครื่องมือมีปุ่มทางด่วนสำหรับฟีเจอร์ที่ใช้งานบ่อย ส่วนนี้จะแนะนำฟังก์ชันและเอฟเฟกต์ของแต่ละปุ่ม

::: tip
โมเดลตัวอย่าง `vise.3mf` ถูกใช้เป็นค่าเริ่มต้นสำหรับการสาธิต
:::

## รายการฟังก์ชัน

- [เปิดไฟล์](/th/toolbar/open-file) — โหลดโมเดล 3D จากพื้นที่จัดเก็บในเครื่อง
- [สลับแกน](/th/toolbar/axis-switch) — สลับระหว่างทิศทาง Y↑ และ Z↑
- [โหมดมุมมอง](/th/toolbar/perspective-mode) — สลับระหว่างโพรเจกชันแบบเปอร์สเปคทีฟและออร์โธกราฟิก
- [จัดการวัสดุ](/th/toolbar/material-manager) — ดูและแก้ไขคุณสมบัติวัสดุของโมเดล
- [การตั้งค่าการเรนเดอร์](/th/toolbar/render-settings) — ปรับพารามิเตอร์การเรนเดอร์และเอฟเฟกต์ภาพ
- [เครื่องเล่นแอนิเมชัน](/th/toolbar/animation-player) — เล่นข้อมูลแอนิเมชันที่ฝังอยู่ในโมเดล
- [จัดการแท่นพิมพ์](/th/toolbar/bed-management) — การแสดงผลและการตั้งค่าแท่นพิมพ์ 3D
- [ประวัติ](/th/toolbar/history) — ดูโมเดลที่โหลดก่อนหน้านี้
- [ข้อมูลโมเดล](/th/toolbar/model-info) — ดูข้อมูลโดยละเอียดเกี่ยวกับโมเดลปัจจุบัน
- [เต็มหน้าจอ](/th/toolbar/fullscreen) — สลับโหมดการแสดงผลแบบเต็มหน้าจอ
- [ควบคุมแถบด้านข้าง](/th/toolbar/sidebar-control) — แสดง/ซ่อนแผงด้านซ้ายและขวา
- [จัดการแคช](/th/toolbar/cache-management) — จัดการข้อมูลแคชของแอปพลิเคชัน
- [การตั้งค่าระบบ](/th/toolbar/system-settings) — กำหนดค่ากำหนดของแอปพลิเคชัน
