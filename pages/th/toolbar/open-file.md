# เปิดไฟล์

คลิกปุ่ม **เปิดไฟล์** ในแถบเครื่องมือเพื่อเปิดกล่องโต้ตอบการเลือกไฟล์ของระบบปฏิบัติการและโหลดไฟล์โมเดล 3D

คุณยังสามารถลากและวางไฟล์ลงในหน้าต่างโดยตรง หรือวางจากคลิปบอร์ด (คัดลอกไฟล์แล้วกด `Ctrl+V`)

![](/screenshots/toolbar/en/open-file-dialog.png)

หลังจากโหลดแล้ว แผงด้านขวาจะแสดงรายการไฟล์ 3D ที่รองรับทั้งหมดในไดเรกทอรีเดียวกันโดยอัตโนมัติเพื่อให้สลับได้อย่างรวดเร็ว

![](/screenshots/toolbar/en/file-list-after-open.png)
