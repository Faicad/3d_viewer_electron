# การตั้งค่าระบบ

คลิกปุ่ม **การตั้งค่าระบบ** ในแถบเครื่องมือเพื่อเปิดแผงการตั้งค่าแอปพลิเคชันและกำหนดค่ากำหนด

ตัวเลือกการตั้งค่า:

- **ภาษา** — สลับระหว่างอินเทอร์เฟซภาษาจีนและภาษาอังกฤษ
- **ธีม** — โหมดสว่าง / โหมดมืด / ตามระบบ
- **ไดเรกทอรีเริ่มต้น** — ตั้งค่าไดเรกทอรีไฟล์เริ่มต้นเมื่อเริ่มต้น

![](/screenshots/toolbar/en/system-settings-panel.png)

การตั้งค่าทั้งหมดมีผลทันทีโดยไม่ต้องรีสตาร์ทแอปพลิเคชัน
