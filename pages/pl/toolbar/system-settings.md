# Ustawienia systemowe

Kliknij przycisk **Ustawienia systemowe** na pasku narzędzi, aby otworzyć panel ustawień aplikacji i skonfigurować preferencje.

Opcje konfiguracji:

- **Język** — Przełączanie między interfejsem chińskim i angielskim
- **Motyw** — Tryb jasny / Tryb ciemny / Śledź system
- **Domyślny katalog** — Ustawienie domyślnego katalogu plików przy uruchomieniu

![](/screenshots/toolbar/en/system-settings-panel.png)

Wszystkie ustawienia są stosowane natychmiast bez ponownego uruchamiania aplikacji.
