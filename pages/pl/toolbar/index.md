# Pasek narzędzi

Pasek narzędzi zapewnia przyciski szybkiego dostępu do najczęściej używanych funkcji. Ta sekcja opisuje funkcję i działanie każdego przycisku.

::: tip
Domyślnie do ilustracji używany jest model demonstracyjny `vise.3mf`.
:::

## Lista funkcji

- [Otwórz plik](/pl/toolbar/open-file) — Wczytaj modele 3D z pamięci lokalnej
- [Przełączanie osi](/pl/toolbar/axis-switch) — Przełączanie między orientacją Y↑ i Z↑
- [Tryb perspektywy](/pl/toolbar/perspective-mode) — Przełączanie między projekcją perspektywiczną i ortograficzną
- [Zarządzanie materiałami](/pl/toolbar/material-manager) — Przeglądanie i edycja właściwości materiałów
- [Ustawienia renderowania](/pl/toolbar/render-settings) — Dostosowanie parametrów renderowania i efektów wizualnych
- [Odtwarzacz animacji](/pl/toolbar/animation-player) — Odtwarzanie danych animacji osadzonych w modelach
- [Zarządzanie stołem](/pl/toolbar/bed-management) — Wizualizacja i ustawienia stołu druku 3D
- [Historia](/pl/toolbar/history) — Przeglądanie wcześniej wczytanych modeli
- [Informacje o modelu](/pl/toolbar/model-info) — Wyświetlanie szczegółowych informacji o bieżącym modelu
- [Pełny ekran](/pl/toolbar/fullscreen) — Przełączanie trybu pełnoekranowego
- [Sterowanie panelem bocznym](/pl/toolbar/sidebar-control) — Pokazywanie/ukrywanie lewego i prawego panelu
- [Zarządzanie pamięcią podręczną](/pl/toolbar/cache-management) — Zarządzanie danymi pamięci podręcznej aplikacji
- [Ustawienia systemowe](/pl/toolbar/system-settings) — Konfiguracja preferencji aplikacji
