# IFC — BIM

IFC (Industry Foundation Classes) is the international standard data format in the BIM domain for digital description of buildings and infrastructure. Parsed and rendered via the web-ifc library.

## Screenshot

![IFC](/screenshots/formats/ifc.png)

## Format Info

| Property | Value |
| --- | --- |
| Extensions | `.ifc` |
| Category | BIM |
| Render Type | Standard triangle mesh rendering |

## Supported Features

- PBR material rendering
- Standard triangle mesh display

### General Features

- Drag & drop: drag files directly into the window
- Click to upload: select via file dialog
- Clipboard paste: Ctrl+V after copying
- OrbitControls: rotate / pan / zoom
- Scene tree: hierarchical model structure
- Model export: download as STL or GLB
