# Gestione piano

Fai clic sul pulsante **Gestione piano** nella barra degli strumenti per attivare/disattivare la visibilità del piano di stampa 3D.

L'app decide automaticamente lo stato iniziale in base al tipo di modello:

- **Modelli CAD** (STL / STEP / 3MF ecc.): **piano visibile** per default
- **Altri modelli** (GLB / OBJ / PLY ecc.): **piano nascosto** per default

Il `vise.3mf` attualmente caricato è un file 3MF, quindi il piano viene visualizzato per default.
