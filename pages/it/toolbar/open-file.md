# Apri file

Fai clic sul pulsante **Apri file** nella barra degli strumenti per aprire la finestra di dialogo nativa di selezione file del sistema operativo e caricare un file modello 3D.

Puoi anche trascinare e rilasciare i file direttamente nella finestra o incollare dagli appunti (copia un file e premi `Ctrl+V`).

![](/screenshots/toolbar/en/open-file-dialog.png)

Una volta caricato, il pannello destro elenca automaticamente tutti i file 3D supportati nella stessa directory per un cambio rapido.

![](/screenshots/toolbar/en/file-list-after-open.png)
