# Info modello

Fai clic sul pulsante **Info modello** nella barra degli strumenti per aprire il pannello delle informazioni sul modello e visualizzare i dati dettagliati del modello corrente.

Le informazioni visualizzate includono:

- **Numero di vertici** — Totale dei vertici
- **Numero di facce** — Totale dei triangoli
- **Dimensione file** — Spazio occupato dal file del modello su disco
- **Bounding box** — Dimensioni del modello lungo gli assi X/Y/Z
- **Numero di materiali** — Quantità di materiali utilizzati
- **Formato file** — Tipo di formato file caricato

![](/screenshots/toolbar/en/model-info-panel.png)

Ispeziona rapidamente le statistiche di base del modello a colpo d'occhio.
