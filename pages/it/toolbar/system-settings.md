# Impostazioni sistema

Fai clic sul pulsante **Impostazioni sistema** nella barra degli strumenti per aprire il pannello delle impostazioni dell'applicazione e configurare le preferenze.

Le opzioni di configurazione includono:

- **Lingua** — Alterna tra interfaccia in cinese e inglese
- **Tema** — Modalità chiara / Modalità scura / Segui sistema
- **Directory predefinita** — Imposta la directory predefinita all'avvio

![](/screenshots/toolbar/en/system-settings-panel.png)

Tutte le impostazioni hanno effetto immediato senza riavviare l'applicazione.
