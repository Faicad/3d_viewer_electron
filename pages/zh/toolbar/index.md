# 工具栏

工具栏提供了常用功能的快捷按钮，方便快速访问。以下逐一介绍每个按钮的功能和效果。

::: tip 提示
默认加载 `vise.3mf` 演示模型进行效果展示。
:::

## 功能列表

- [打开文件](/zh/toolbar/open-file) — 从本地加载 3D 模型文件
- [坐标轴切换](/zh/toolbar/axis-switch) — 在 Y↑ 和 Z↑ 朝向之间切换
- [透视模式](/zh/toolbar/perspective-mode) — 在透视投影和正交投影之间切换
- [材质管理](/zh/toolbar/material-manager) — 查看和编辑模型材质属性
- [渲染设置](/zh/toolbar/render-settings) — 调整渲染参数和视觉效果
- [动画播放](/zh/toolbar/animation-player) — 播放模型中的动画数据
- [热床管理](/zh/toolbar/bed-management) — 3D 打印热床可视化和设置
- [历史记录](/zh/toolbar/history) — 查看已加载过的模型
- [模型信息](/zh/toolbar/model-info) — 查看当前模型的详细信息
- [全屏显示](/zh/toolbar/fullscreen) — 切换全屏显示模式
- [边栏控制](/zh/toolbar/sidebar-control) — 显示/隐藏左面板和右面板
- [缓存管理](/zh/toolbar/cache-management) — 管理应用缓存数据
- [系统设置](/zh/toolbar/system-settings) — 配置应用偏好设置
