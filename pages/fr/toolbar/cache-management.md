# Gestion du cache

Cliquez sur le bouton **Gestion du cache** dans la barre d'outils pour ouvrir le panneau de configuration du cache et gérer les données de cache de l'application.

Fonctionnalités :

- **Voir l'utilisation du cache** — Afficher l'espace disque occupé par les données en cache
- **Vider le cache** — Effacer toutes les données en cache en un clic
- **Détail du cache** — Voir l'utilisation par type de cache (conversion de modèles, miniatures, etc.)

![](/screenshots/toolbar/en/cache-management-panel.png)

Un nettoyage régulier du cache libère de l'espace disque. Recommandé avant de charger de grands modèles.
