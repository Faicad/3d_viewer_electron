# Informations du modèle

Cliquez sur le bouton **Informations du modèle** dans la barre d'outils pour ouvrir le panneau d'informations et voir les données détaillées du modèle actuel.

Les informations affichées incluent :

- **Nombre de sommets** — Total des sommets
- **Nombre de faces** — Total des triangles
- **Taille du fichier** — Espace occupé par le fichier sur le disque
- **Boîte englobante** — Dimensions du modèle sur les axes X/Y/Z
- **Nombre de matériaux** — Quantité de matériaux utilisés
- **Format de fichier** — Type de format de fichier chargé

![](/screenshots/toolbar/en/model-info-panel.png)

Inspectez rapidement les statistiques de base du modèle en un coup d'œil.
