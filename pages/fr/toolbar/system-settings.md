# Paramètres système

Cliquez sur le bouton **Paramètres système** dans la barre d'outils pour ouvrir le panneau de configuration de l'application et ajuster les préférences.

Les options de configuration incluent :

- **Langue** — Basculer entre l'interface en chinois et en anglais
- **Thème** — Mode clair / Mode sombre / Suivre le système
- **Répertoire par défaut** — Définir le répertoire de fichiers par défaut au démarrage

![](/screenshots/toolbar/en/system-settings-panel.png)

Tous les réglages prennent effet immédiatement sans redémarrer l'application.
