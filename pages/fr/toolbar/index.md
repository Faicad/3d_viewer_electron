# Barre d'outils

La barre d'outils fournit des boutons d'accès rapide aux fonctions les plus utilisées. Cette section présente la fonction et l'effet de chaque bouton.

::: tip
Le modèle de démonstration `vise.3mf` est utilisé par défaut pour les illustrations.
:::

## Liste des fonctions

- [Ouvrir un fichier](/fr/toolbar/open-file) — Charger des modèles 3D depuis le stockage local
- [Changement d'axe](/fr/toolbar/axis-switch) — Basculer entre l'orientation Y↑ et Z↑
- [Mode perspective](/fr/toolbar/perspective-mode) — Basculer entre projection perspective et orthographique
- [Gestionnaire de matériaux](/fr/toolbar/material-manager) — Voir et modifier les propriétés des matériaux
- [Paramètres de rendu](/fr/toolbar/render-settings) — Ajuster les paramètres de rendu et les effets visuels
- [Lecteur d'animations](/fr/toolbar/animation-player) — Lire les données d'animation intégrées aux modèles
- [Gestion du plateau](/fr/toolbar/bed-management) — Visualisation et configuration du plateau d'impression 3D
- [Historique](/fr/toolbar/history) — Voir les modèles chargés précédemment
- [Informations du modèle](/fr/toolbar/model-info) — Voir les détails du modèle actuel
- [Plein écran](/fr/toolbar/fullscreen) — Activer/désactiver le mode plein écran
- [Contrôle des panneaux](/fr/toolbar/sidebar-control) — Afficher/masquer les panneaux latéraux
- [Gestion du cache](/fr/toolbar/cache-management) — Gérer les données de cache de l'application
- [Paramètres système](/fr/toolbar/system-settings) — Configurer les préférences de l'application
