# Gestion du plateau

Cliquez sur le bouton **Gestion du plateau** dans la barre d'outils pour activer/désactiver la visibilité du plateau d'impression 3D.

L'application décide automatiquement de l'état initial selon le type de modèle :

- **Modèles CAO** (STL / STEP / 3MF etc.) : **plateau affiché** par défaut
- **Autres modèles** (GLB / OBJ / PLY etc.) : **plateau caché** par défaut

Le `vise.3mf` actuellement chargé est un fichier 3MF, donc le plateau est affiché par défaut.

Idéal pour les utilisateurs d'impression 3D qui souhaitent prévisualiser le placement du modèle avant le tranchage.
