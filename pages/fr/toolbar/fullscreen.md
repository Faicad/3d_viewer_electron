# Plein écran

Cliquez sur le bouton **Plein écran** dans la barre d'outils pour passer la vue en mode plein écran, masquant tous les panneaux et barres d'outils pour maximiser la zone d'affichage 3D.

Appuyez sur `Esc` ou recliquez sur le bouton pour quitter le mode plein écran.

![](/screenshots/toolbar/en/fullscreen-viewport.png)

Idéal pour se concentrer sur les détails du modèle ou faire des présentations.
