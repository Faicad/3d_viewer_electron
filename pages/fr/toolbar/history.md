# Historique

Cliquez sur le bouton **Historique** dans la barre d'outils pour ouvrir le panneau d'historique affichant les modèles que vous avez chargés précédemment.

- **Entrées de fichiers** — Chaque modèle chargé est affiché avec son nom, son heure de chargement et un aperçu miniature
- **Rouvrir** — Cliquez sur une entrée pour recharger ce fichier

![](/screenshots/toolbar/en/history-panel.png)

L'historique persiste entre les sessions, facilitant la réouverture des modèles récemment consultés.
