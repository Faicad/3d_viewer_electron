# Ouvrir un fichier

Cliquez sur le bouton **Ouvrir un fichier** dans la barre d'outils pour ouvrir la boîte de dialogue native de sélection de fichiers du système d'exploitation et charger un fichier de modèle 3D.

Vous pouvez également faire glisser-déposer des fichiers directement dans la fenêtre, ou coller depuis le presse-papiers (copiez un fichier puis appuyez sur `Ctrl+V`).

![](/screenshots/toolbar/en/open-file-dialog.png)

Une fois chargé, le panneau droit liste automatiquement tous les fichiers 3D compatibles dans le même répertoire pour un changement rapide.

![](/screenshots/toolbar/en/file-list-after-open.png)
