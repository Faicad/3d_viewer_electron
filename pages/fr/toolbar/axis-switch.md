# Changement d'axe

Cliquez sur le bouton **Y↑** / **Z↑** dans la barre d'outils pour basculer l'orientation globale de l'axe vertical.

L'application sélectionne automatiquement l'orientation par défaut selon le type de modèle :

- **Modèles CAO** (STL / STEP / 3MF etc.) : **Z vers le haut (Z↑)** par défaut
- **Modèles GLB / glTF** : **Y vers le haut (Y↑)** par défaut

Le `vise.3mf` actuellement chargé est un fichier 3MF, affiché avec Z↑ par défaut.

## Mode Z↑

Utilise l'axe Z comme direction vers le haut, adapté à l'architecture, la CAO et les modèles d'ingénierie.

![](/screenshots/toolbar/en/axis-z-up.png)

## Mode Y↑

Utilise l'axe Y comme direction vers le haut, adapté à la plupart des modélisations 3D et des assets de jeux.

![](/screenshots/toolbar/en/axis-y-up.png)

L'indicateur d'axes de coordonnées dans le coin inférieur droit se met à jour après le changement.
