# Режим перспективы

Нажмите кнопку **Перспектива/Ортография** на панели инструментов для переключения между перспективной и ортографической проекцией.

## Перспективный режим

Имитирует перспективу человеческого глаза — удаленные объекты выглядят меньше. Идеально подходит для наблюдения глубины и пространственных отношений.

![](/screenshots/toolbar/en/perspective-mode.png)

## Ортографический режим

Устраняет перспективные искажения — все объекты отображаются в одинаковом масштабе независимо от расстояния. Подходит для проверки размеров и выравнивания.

![](/screenshots/toolbar/en/orthographic-mode.png)
