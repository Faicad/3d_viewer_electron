# Переключение осей

Нажмите кнопку **Y↑** / **Z↑** на панели инструментов, чтобы переключить глобальное направление вертикальной оси.

Приложение автоматически выбирает ориентацию по умолчанию в зависимости от типа модели:

- **CAD-модели** (STL / STEP / 3MF и др.): по умолчанию **Z вверх (Z↑)**
- **GLB / glTF модели**: по умолчанию **Y вверх (Y↑)**

Текущая загруженная модель `vise.3mf` — файл 3MF, отображается с Z↑ по умолчанию.

## Режим Z↑

Использует ось Z как направление вверх, подходит для архитектурных, CAD и инженерных моделей.

![](/screenshots/toolbar/en/axis-z-up.png)

## Режим Y↑

Использует ось Y как направление вверх, подходит для большинства 3D-моделей и игровых ресурсов.

![](/screenshots/toolbar/en/axis-y-up.png)

Индикатор осей координат в правом нижнем углу синхронно обновляется после переключения.
