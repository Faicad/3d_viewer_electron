# История

Нажмите кнопку **История** на панели инструментов, чтобы открыть панель истории с ранее загруженными моделями.

- **Записи файлов** — Каждая загруженная модель отображается с именем файла, временем загрузки и миниатюрой
- **Повторное открытие** — Нажмите на любую запись, чтобы перезагрузить этот файл

![](/screenshots/toolbar/en/history-panel.png)

История сохраняется между сеансами, что позволяет легко открывать недавно просмотренные модели.
