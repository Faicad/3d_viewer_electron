# Панель инструментов

Панель инструментов предоставляет кнопки быстрого доступа к часто используемым функциям. В этом разделе описывается назначение и действие каждой кнопки.

::: tip
Для иллюстрации по умолчанию используется демо-модель `vise.3mf`.
:::

## Список функций

- [Открыть файл](/ru/toolbar/open-file) — Загрузить 3D-модели из локального хранилища
- [Переключение осей](/ru/toolbar/axis-switch) — Переключение между Y↑ и Z↑
- [Режим перспективы](/ru/toolbar/perspective-mode) — Переключение между перспективной и ортографической проекцией
- [Управление материалами](/ru/toolbar/material-manager) — Просмотр и редактирование свойств материалов
- [Настройки рендеринга](/ru/toolbar/render-settings) — Настройка параметров рендеринга и визуальных эффектов
- [Проигрыватель анимаций](/ru/toolbar/animation-player) — Воспроизведение анимационных данных в моделях
- [Управление платформой](/ru/toolbar/bed-management) — Визуализация и настройка платформы 3D-печати
- [История](/ru/toolbar/history) — Просмотр ранее загруженных моделей
- [Информация о модели](/ru/toolbar/model-info) — Просмотр детальной информации о текущей модели
- [Полный экран](/ru/toolbar/fullscreen) — Переключение полноэкранного режима
- [Управление боковыми панелями](/ru/toolbar/sidebar-control) — Показать/скрыть левую и правую панели
- [Управление кэшем](/ru/toolbar/cache-management) — Управление кэшированными данными приложения
- [Системные настройки](/ru/toolbar/system-settings) — Настройка параметров приложения
