# Информация о модели

Нажмите кнопку **Информация о модели** на панели инструментов, чтобы открыть панель информации и просмотреть детальные данные о текущей модели.

Отображаемая информация:

- **Количество вершин** — Общее количество вершин
- **Количество граней** — Общее количество треугольников
- **Размер файла** — Объем файла модели на диске
- **Граничный прямоугольник** — Размеры модели по осям X/Y/Z
- **Количество материалов** — Количество используемых материалов
- **Формат файла** — Тип загруженного формата файла
