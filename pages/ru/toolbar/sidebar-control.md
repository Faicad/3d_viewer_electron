# Управление боковыми панелями

Панель инструментов предоставляет кнопки **Левая панель** и **Правая панель** для независимого переключения видимости левой и правой боковых панелей.

## Левая панель

Отображает дерево сцены с иерархической структурой модели.

Нажмите для переключения видимости:

![](/screenshots/toolbar/en/sidebar-left-visible.png)

Скрыто для освобождения места на видовом экране:

![](/screenshots/toolbar/en/sidebar-left-hidden.png)

## Правая панель

Отображает список файлов и информацию о модели.

Нажмите для переключения видимости:

![](/screenshots/toolbar/en/sidebar-right-visible.png)

![](/screenshots/toolbar/en/sidebar-right-hidden.png)

Обе панели управляются независимо для гибкой компоновки рабочего пространства.
