# Настройки рендеринга

Нажмите кнопку **Настройки рендеринга** на панели инструментов, чтобы открыть панель параметров рендеринга и настроить эффекты отображения сцены.

Настраиваемые параметры:

- **Карта окружения** — Переключение различных HDR-карт окружения для изменения освещения
- **Наложение каркаса** — Включение/отключение отображения полигональной сетки
- **Цвет фона** — Изменить цвет фона видового экрана
- **Тени** — Включение или отключение рендеринга теней

![](/screenshots/toolbar/en/render-settings-panel.png)

Изменения отражаются в видовом экране в реальном времени.
