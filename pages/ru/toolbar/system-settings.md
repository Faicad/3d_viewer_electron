# Системные настройки

Нажмите кнопку **Системные настройки** на панели инструментов, чтобы открыть панель настроек приложения и изменить параметры.

Настройки включают:

- **Язык** — Переключение между китайским и английским интерфейсом
- **Тема** — Светлая тема / Темная тема / Следовать системе
- **Каталог по умолчанию** — Установка каталога файлов по умолчанию при запуске

![](/screenshots/toolbar/en/system-settings-panel.png)

Все настройки вступают в силу немедленно без перезапуска приложения.
