# Открыть файл

Нажмите кнопку **Открыть файл** на панели инструментов, чтобы открыть системный диалог выбора файлов и загрузить 3D-модель.

Вы также можете перетащить файлы прямо в окно или вставить из буфера обмена (скопируйте файл и нажмите `Ctrl+V`).

![](/screenshots/toolbar/en/open-file-dialog.png)

После загрузки правая панель автоматически отобразит все поддерживаемые 3D-файлы в той же директории для быстрого переключения.

![](/screenshots/toolbar/en/file-list-after-open.png)
