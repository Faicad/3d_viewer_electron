# Управление платформой

Нажмите кнопку **Управление платформой** на панели инструментов, чтобы включить/отключить отображение платформы 3D-печати.

Приложение автоматически определяет начальное состояние в зависимости от типа модели:

- **CAD-модели** (STL / STEP / 3MF и др.): **платформа показана** по умолчанию
- **Другие модели** (GLB / OBJ / PLY и др.): **платформа скрыта** по умолчанию

Текущая загруженная модель `vise.3mf` — файл 3MF, поэтому платформа отображается по умолчанию.

![](/screenshots/toolbar/en/bed-management-panel.png)

Идеально подходит для пользователей 3D-печати, чтобы просмотреть размещение модели перед нарезкой.
