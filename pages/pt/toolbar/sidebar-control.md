# Controle da barra lateral

A barra de ferramentas fornece botões **Painel esquerdo** e **Painel direito** para alternar independentemente a visibilidade das barras laterais esquerda e direita.

## Painel esquerdo

Mostra a árvore da cena com a estrutura hierárquica do modelo.

Clique para alternar a visibilidade:

![](/screenshots/toolbar/en/sidebar-left-visible.png)

Oculto para liberar mais espaço no visor:

![](/screenshots/toolbar/en/sidebar-left-hidden.png)

## Painel direito

Mostra a lista de arquivos e informações do modelo.

Clique para alternar a visibilidade:

![](/screenshots/toolbar/en/sidebar-right-visible.png)

![](/screenshots/toolbar/en/sidebar-right-hidden.png)

Ambos os painéis são controlados independentemente para um layout de espaço de trabalho flexível.
