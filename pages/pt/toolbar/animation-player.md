# Player de animação

Clique no botão **Player de animação** na barra de ferramentas para abrir a caixa de diálogo do player de animação e reproduzir dados de animação incorporados no modelo.

Formatos suportados: GLB/GLTF (animação esquelética e morph targets), FBX (animação esquelética), DAE, BVH (captura de movimento), MD2 (animação de vértices).

> Consulte a página [Player de animação](/pt/features/animation-player) para documentação detalhada.
