# Gerenciamento de mesa

Clique no botão **Gerenciamento de mesa** na barra de ferramentas para alternar a visibilidade da mesa de impressão 3D.

O aplicativo decide automaticamente o estado inicial com base no tipo de modelo:

- **Modelos CAD** (STL / STEP / 3MF etc.): **mesa visível** por padrão
- **Outros modelos** (GLB / OBJ / PLY etc.): **mesa oculta** por padrão

O `vise.3mf` atualmente carregado é um arquivo 3MF, então a mesa é exibida por padrão.

![](/screenshots/toolbar/en/bed-management-panel.png)

Ideal para usuários de impressão 3D visualizarem o posicionamento do modelo antes do fatiamento.
