# Histórico

Clique no botão **Histórico** na barra de ferramentas para abrir o painel de histórico mostrando os modelos carregados anteriormente.

- **Entradas de arquivos** — Cada modelo carregado é exibido com nome do arquivo, hora do carregamento e miniatura de pré-visualização
- **Reabrir** — Clique em qualquer entrada para recarregar esse arquivo

![](/screenshots/toolbar/en/history-panel.png)

O histórico persiste entre sessões, facilitando a reabertura de modelos visualizados recentemente.
