# Alternar eixo

Clique no botão **Y↑** / **Z↑** na barra de ferramentas para alternar a orientação do eixo vertical global.

O aplicativo seleciona automaticamente a orientação padrão com base no tipo de modelo:

- **Modelos CAD** (STL / STEP / 3MF etc.): **Z para cima (Z↑)** por padrão
- **Modelos GLB / glTF**: **Y para cima (Y↑)** por padrão

O `vise.3mf` atualmente carregado é um arquivo 3MF, exibido com Z↑ por padrão.

## Modo Z↑

Usa o eixo Z como direção para cima, adequado para arquitetura, CAD e modelos de engenharia.

![](/screenshots/toolbar/en/axis-z-up.png)

## Modo Y↑

Usa o eixo Y como direção para cima, adequado para a maioria dos modelos 3D e assets de jogos.

![](/screenshots/toolbar/en/axis-y-up.png)

O indicador de eixos de coordenadas no canto inferior direito é atualizado após a alternância.
