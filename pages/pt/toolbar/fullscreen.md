# Tela cheia

Clique no botão **Tela cheia** na barra de ferramentas para alternar o visor para o modo de tela cheia, ocultando todos os painéis e barras de ferramentas para maximizar a área de exibição 3D.

Pressione `Esc` ou clique no botão novamente para sair do modo tela cheia.

![](/screenshots/toolbar/en/fullscreen-viewport.png)

Ideal para focar nos detalhes do modelo ou fazer apresentações.
