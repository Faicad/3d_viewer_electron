# Gerenciamento de cache

Clique no botão **Gerenciamento de cache** na barra de ferramentas para abrir o painel de configurações de cache e gerenciar os dados de cache do aplicativo.

Recursos:

- **Ver uso do cache** — Exibir o espaço em disco ocupado pelos dados em cache
- **Limpar cache** — Limpar todos os dados em cache com um clique
- **Detalhamento do cache** — Ver o uso por tipo de cache (conversão de modelos, miniaturas, etc.)

![](/screenshots/toolbar/en/cache-management-panel.png)

A limpeza regular do cache libera espaço em disco. Recomendado antes de carregar modelos grandes.
