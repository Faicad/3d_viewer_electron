# Abrir arquivo

Clique no botão **Abrir arquivo** na barra de ferramentas para abrir a caixa de diálogo nativa de seleção de arquivos do sistema operacional e carregar um arquivo de modelo 3D.

Você também pode arrastar e soltar arquivos diretamente na janela, ou colar da área de transferência (copie um arquivo e pressione `Ctrl+V`).

![](/screenshots/toolbar/en/open-file-dialog.png)

Após o carregamento, o painel direito lista automaticamente todos os arquivos 3D compatíveis no mesmo diretório para alternância rápida.

![](/screenshots/toolbar/en/file-list-after-open.png)
