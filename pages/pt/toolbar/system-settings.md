# Configurações do sistema

Clique no botão **Configurações do sistema** na barra de ferramentas para abrir o painel de configurações do aplicativo e ajustar as preferências.

As opções de configuração incluem:

- **Idioma** — Alternar entre interface em chinês e inglês
- **Tema** — Modo claro / Modo escuro / Seguir sistema
- **Diretório padrão** — Definir o diretório de arquivos padrão na inicialização

![](/screenshots/toolbar/en/system-settings-panel.png)

Todas as configurações entram em vigor imediatamente sem reiniciar o aplicativo.
