# Barra de ferramentas

A barra de ferramentas fornece botões de acesso rápido para funções usadas com frequência. Esta seção apresenta a função e o efeito de cada botão.

::: tip
O modelo de demonstração `vise.3mf` é usado por padrão para ilustração.
:::

## Lista de funções

- [Abrir arquivo](/pt/toolbar/open-file) — Carregar modelos 3D do armazenamento local
- [Alternar eixo](/pt/toolbar/axis-switch) — Alternar entre orientação Y↑ e Z↑
- [Modo perspectiva](/pt/toolbar/perspective-mode) — Alternar entre projeção perspectiva e ortográfica
- [Gerenciador de materiais](/pt/toolbar/material-manager) — Ver e editar propriedades de materiais do modelo
- [Configurações de renderização](/pt/toolbar/render-settings) — Ajustar parâmetros de renderização e efeitos visuais
- [Player de animação](/pt/toolbar/animation-player) — Reproduzir dados de animação incorporados em modelos
- [Gerenciamento de mesa](/pt/toolbar/bed-management) — Visualização e configuração da mesa de impressão 3D
- [Histórico](/pt/toolbar/history) — Ver modelos carregados anteriormente
- [Informações do modelo](/pt/toolbar/model-info) — Ver informações detalhadas do modelo atual
- [Tela cheia](/pt/toolbar/fullscreen) — Alternar modo de exibição em tela cheia
- [Controle da barra lateral](/pt/toolbar/sidebar-control) — Mostrar/ocultar painéis esquerdo e direito
- [Gerenciamento de cache](/pt/toolbar/cache-management) — Gerenciar dados de cache do aplicativo
- [Configurações do sistema](/pt/toolbar/system-settings) — Configurar preferências do aplicativo
