# Informações do modelo

Clique no botão **Informações do modelo** na barra de ferramentas para abrir o painel de informações do modelo e ver dados detalhados sobre o modelo atual.

As informações exibidas incluem:

- **Número de vértices** — Total de vértices
- **Número de faces** — Total de triângulos
- **Tamanho do arquivo** — Espaço ocupado pelo arquivo do modelo em disco
- **Caixa delimitadora** — Dimensões do modelo nos eixos X/Y/Z
- **Número de materiais** — Quantidade de materiais utilizados
- **Formato do arquivo** — Tipo de formato de arquivo carregado

![](/screenshots/toolbar/en/model-info-panel.png)

Inspecione rapidamente as estatísticas básicas do modelo de uma só vez.
