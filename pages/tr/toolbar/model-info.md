# Model Bilgisi

Araç çubuğundaki **Model Bilgisi** düğmesine tıklayarak model bilgi panelini açın ve geçerli model hakkında ayrıntılı verileri görüntüleyin.

Görüntülenen bilgiler:

- **Köşe Sayısı** — Toplam köşe sayısı
- **Yüz Sayısı** — Toplam üçgen sayısı
- **Dosya Boyutu** — Disk üzerindeki model dosya boyutu
- **Sınırlama Kutusu** — Modelin X/Y/Z eksenlerindeki boyutları
- **Malzeme Sayısı** — Kullanılan malzeme sayısı
- **Dosya Biçimi** — Yüklenen dosya biçimi türü

![](/screenshots/toolbar/en/model-info-panel.png)

Modelin temel istatistiklerine bir bakışta hızlıca göz atın.
