# Systeminställningar

Klicka på knappen **Systeminställningar** i verktygsfältet för att öppna applikationsinställningspanelen och konfigurera preferenser.

Inställningsalternativ:

- **Språk** — Växla mellan kinesiskt och engelskt gränssnitt
- **Tema** — Ljust läge / Mörkt läge / Följ systemet
- **Standardkatalog** — Ange standard filkatalog vid start

![](/screenshots/toolbar/en/system-settings-panel.png)

Alla inställningar träder i kraft omedelbart utan att applikationen behöver startas om.
