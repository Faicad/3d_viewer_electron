# Modellinfo

Klicka på knappen **Modellinfo** i verktygsfältet för att öppna modellinformationspanelen och visa detaljerad data om den aktuella modellen.

Information som visas:

- **Antal vertex** — Totalt antal vertexpunkter
- **Antal ytor** — Totalt antal trianglar
- **Filstorlek** — Modellfilens utrymme på disken
- **Begränsningsbox** — Modellens dimensioner längs X/Y/Z-axlarna
- **Antal material** — Antal använda material
- **Filformat** — Typ av laddat filformat

![](/screenshots/toolbar/en/model-info-panel.png)

Inspektera snabbt modellens grundläggande statistik i ett ögonkast.
