# Perspektivläge

Klicka på knappen **Perspektiv/Ortografisk** i verktygsfältet för att växla mellan perspektiv- och ortografisk projektion.

## Perspektivläge

Simulerar mänskligt ögonperspektiv — objekt längre bort verkar mindre. Idealisk för att observera djup och rumsliga relationer.

![](/screenshots/toolbar/en/perspective-mode.png)

## Ortografiskt läge

Eliminerar perspektivförvrängning — alla objekt visas i samma skala oavsett avstånd. Lämpligt för att kontrollera dimensioner och inriktning.

![](/screenshots/toolbar/en/orthographic-mode.png)
