# Bäddhantering

Klicka på knappen **Bäddhantering** i verktygsfältet för att växla synligheten för 3D-utskriftsbädden.

Appen bestämmer automatiskt initialtillstånd baserat på modelltyp:

- **CAD-modeller** (STL / STEP / 3MF etc.): **bädd visas** som standard
- **Andra modeller** (GLB / OBJ / PLY etc.): **bädd dold** som standard

Den aktuella modellen `vise.3mf` är en 3MF-fil, så bädden visas som standard.

![](/screenshots/toolbar/en/bed-management-panel.png)

Idealisk för 3D-utskriftsanvändare att förhandsgranska modellplacering innan slicing.
