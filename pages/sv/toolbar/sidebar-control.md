# Sidofältskontroll

Verktygsfältet har knappar för **Vänster panel** och **Höger panel** för att oberoende visa/dölja vänster och höger sidofält.

## Vänster panel

Visar scenträdet med modellens hierarkiska struktur.

Klicka för att växla synlighet:

![](/screenshots/toolbar/en/sidebar-left-visible.png)

Dold för att frigöra mer visningsutrymme:

![](/screenshots/toolbar/en/sidebar-left-hidden.png)

## Höger panel

Visar fillistan och modellinformation.

Klicka för att växla synlighet:

![](/screenshots/toolbar/en/sidebar-right-visible.png)

![](/screenshots/toolbar/en/sidebar-right-hidden.png)

Båda panelerna styrs oberoende för flexibel arbetsyta.
