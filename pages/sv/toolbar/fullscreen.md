# Helskärm

Klicka på knappen **Helskärm** i verktygsfältet för att växla visningsområdet till helskärmsläge, dölja alla paneler och verktygsfält för att maximera 3D-visningsytan.

Tryck på `Esc` eller klicka på knappen igen för att avsluta helskärmsläget.

![](/screenshots/toolbar/en/fullscreen-viewport.png)

Idealisk för att fokusera på modelldetaljer eller göra presentationer.
