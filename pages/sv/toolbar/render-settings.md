# Renderingsinställningar

Klicka på knappen **Renderingsinställningar** i verktygsfältet för att öppna renderingsparametrarna och justera scenens visningseffekter.

Justerbara parametrar:

- **Omgivningskarta** — Växla mellan olika HDR-omgivningskartor för varierad belysning
- **Trådmodellsöverlagring** — Aktivera/inaktivera trådmodellsvisning
- **Bakgrundsfärg** — Ändra bakgrundsfärgen för visningsområdet
- **Skuggor** — Aktivera eller inaktivera skuggrendering

![](/screenshots/toolbar/en/render-settings-panel.png)

Ändringarna visas i visningsområdet i realtid.
