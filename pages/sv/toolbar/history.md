# Historik

Klicka på knappen **Historik** i verktygsfältet för att öppna historikpanelen som visar modeller du tidigare laddat.

- **Filposter** — Varje laddad modell visas med filnamn, laddningstid och miniatyrförhandsgranskning
- **Öppna igen** — Klicka på en post för att ladda om filen

![](/screenshots/toolbar/en/history-panel.png)

Historiken finns kvar mellan sessioner, vilket gör det enkelt att återöppna nyligen visade modeller.
