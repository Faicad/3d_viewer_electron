# Cachehantering

Klicka på knappen **Cachehantering** i verktygsfältet för att öppna cacheinställningspanelen och hantera applikationens cachedata.

Funktioner:

- **Visa cacheanvändning** — Visa diskutrymme som upptas av cachedata
- **Rensa cache** — Rensa all cachedata med ett klick
- **Cacheuppdelning** — Visa användning per cachetyp (modellkonvertering, miniatyrer, etc.)

![](/screenshots/toolbar/en/cache-management-panel.png)

Regelbunden cacherensning frigör diskutrymme. Rekommenderas innan du laddar stora modeller.
