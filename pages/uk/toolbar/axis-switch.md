# Перемикання осей

Натисніть кнопку **Y↑** / **Z↑** на панелі інструментів, щоб перемкнути глобальний напрямок вертикальної осі.

Додаток автоматично вибирає орієнтацію за замовчуванням залежно від типу моделі:

- **CAD-моделі** (STL / STEP / 3MF тощо): за замовчуванням **Z вгору (Z↑)**
- **GLB / glTF моделі**: за замовчуванням **Y вгору (Y↑)**

Поточна завантажена модель `vise.3mf` — файл 3MF, відображається з Z↑ за замовчуванням.

## Режим Z↑

Використовує вісь Z як напрямок вгору, підходить для архітектурних, CAD та інженерних моделей.

![](/screenshots/toolbar/en/axis-z-up.png)

## Режим Y↑

Використовує вісь Y як напрямок вгору, підходить для більшості 3D-моделей та ігрових ресурсів.

![](/screenshots/toolbar/en/axis-y-up.png)

Індикатор осей координат у правому нижньому куті синхронно оновлюється після перемикання.
