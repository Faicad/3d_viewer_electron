# Налаштування рендерингу

Натисніть кнопку **Налаштування рендерингу** на панелі інструментів, щоб відкрити панель параметрів рендерингу та налаштувати ефекти відображення сцени.

Параметри, які можна налаштувати:

- **Карта оточення** — Перемикання різних HDR-карт оточення для зміни освітлення
- **Накладання каркасу** — Увімкнення/вимкнення відображення полігональної сітки
- **Колір фону** — Змінити колір фону вікна перегляду
- **Тіні** — Увімкнення або вимкнення рендерингу тіней
