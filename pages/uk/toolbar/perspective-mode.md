# Режим перспективи

Натисніть кнопку **Перспектива/Ортографія** на панелі інструментів для перемикання між перспективною та ортографічною проекцією.

## Перспективний режим

Імітує перспективу людського ока — віддалені об'єкти виглядають меншими. Ідеально підходить для спостереження глибини та просторових відносин.

![](/screenshots/toolbar/en/perspective-mode.png)

## Ортографічний режим

Усуває перспективні спотворення — всі об'єкти відображаються в однаковому масштабі незалежно від відстані. Підходить для перевірки розмірів та вирівнювання.

![](/screenshots/toolbar/en/orthographic-mode.png)
