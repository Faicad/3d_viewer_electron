# Панель інструментів

Панель інструментів надає кнопки швидкого доступу до функцій, що найчастіше використовуються. У цьому розділі описується призначення та дія кожної кнопки.

::: tip
Для ілюстрації за замовчуванням використовується демо-модель `vise.3mf`.
:::

## Список функцій

- [Відкрити файл](/uk/toolbar/open-file) — Завантажити 3D-моделі з локального сховища
- [Перемикання осей](/uk/toolbar/axis-switch) — Перемикання між орієнтацією Y↑ та Z↑
- [Режим перспективи](/uk/toolbar/perspective-mode) — Перемикання між перспективною та ортографічною проекцією
- [Керування матеріалами](/uk/toolbar/material-manager) — Перегляд та редагування властивостей матеріалів моделі
- [Налаштування рендерингу](/uk/toolbar/render-settings) — Налаштування параметрів рендерингу та візуальних ефектів
- [Програвач анімацій](/uk/toolbar/animation-player) — Відтворення анімаційних даних, вбудованих у моделі
- [Керування платформою](/uk/toolbar/bed-management) — Візуалізація та налаштування платформи 3D-друку
- [Історія](/uk/toolbar/history) — Перегляд раніше завантажених моделей
- [Інформація про модель](/uk/toolbar/model-info) — Перегляд детальної інформації про поточну модель
- [Повний екран](/uk/toolbar/fullscreen) — Перемикання повноекранного режиму
- [Керування бічною панеллю](/uk/toolbar/sidebar-control) — Показати/приховати ліву та праву панелі
- [Керування кешем](/uk/toolbar/cache-management) — Керування даними кешу додатку
- [Системні налаштування](/uk/toolbar/system-settings) — Налаштування параметрів додатку
