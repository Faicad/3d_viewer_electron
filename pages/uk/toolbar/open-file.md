# Відкрити файл

Натисніть кнопку **Відкрити файл** на панелі інструментів, щоб відкрити системний діалог вибору файлів і завантажити файл 3D-моделі.

Ви також можете перетягнути файли безпосередньо у вікно або вставити з буфера обміну (скопіюйте файл і натисніть `Ctrl+V`).

![](/screenshots/toolbar/en/open-file-dialog.png)

Після завантаження права панель автоматично відображає всі підтримувані 3D-файли в тій самій директорії для швидкого перемикання.

![](/screenshots/toolbar/en/file-list-after-open.png)
