# Системні налаштування

Натисніть кнопку **Системні налаштування** на панелі інструментів, щоб відкрити панель налаштувань додатку та змінити параметри.

Параметри налаштувань:

- **Мова** — Перемикання між китайським та англійським інтерфейсом
- **Тема** — Світла тема / Темна тема / Слідувати системі
- **Каталог за замовчуванням** — Встановлення каталогу файлів за замовчуванням при запуску

![](/screenshots/toolbar/en/system-settings-panel.png)

Всі налаштування набувають чинності негайно без перезапуску додатку.
