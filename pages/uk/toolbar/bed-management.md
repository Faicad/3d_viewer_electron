# Керування платформою

Натисніть кнопку **Керування платформою** на панелі інструментів, щоб увімкнути/вимкнути відображення платформи 3D-друку.

Додаток автоматично визначає початковий стан залежно від типу моделі:

- **CAD-моделі** (STL / STEP / 3MF тощо): **платформа показана** за замовчуванням
- **Інші моделі** (GLB / OBJ / PLY тощо): **платформа прихована** за замовчуванням

Поточна завантажена модель `vise.3mf` — файл 3MF, тому платформа відображається за замовчуванням.

![](/screenshots/toolbar/en/bed-management-panel.png)

Ідеально підходить для користувачів 3D-друку, щоб переглянути розміщення моделі перед нарізкою.
