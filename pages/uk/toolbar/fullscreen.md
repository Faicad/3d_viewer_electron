# Повний екран

Натисніть кнопку **Повний екран** на панелі інструментів, щоб перемкнути вікно перегляду в повноекранний режим, приховавши всі панелі та панелі інструментів для максимальної області 3D-відображення.

Натисніть `Esc` або знову натисніть кнопку, щоб вийти з повноекранного режиму.

![](/screenshots/toolbar/en/fullscreen-viewport.png)

Ідеально підходить для фокусування на деталях моделі або проведення презентацій.
