# Керування бічною панеллю

Панель інструментів надає кнопки **Ліва панель** та **Права панель** для незалежного перемикання видимості лівої та правої бічних панелей.

## Ліва панель

Відображає дерево сцени з ієрархічною структурою моделі.

Натисніть для перемикання видимості:

![](/screenshots/toolbar/en/sidebar-left-visible.png)

Приховано для звільнення місця у вікні перегляду:

![](/screenshots/toolbar/en/sidebar-left-hidden.png)

## Права панель

Відображає список файлів та інформацію про модель.

Натисніть для перемикання видимості:

![](/screenshots/toolbar/en/sidebar-right-visible.png)

![](/screenshots/toolbar/en/sidebar-right-hidden.png)

Обидві панелі керуються незалежно для гнучкого компонування робочого простору.
